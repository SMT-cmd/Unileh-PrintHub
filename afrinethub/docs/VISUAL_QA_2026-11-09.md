# AfriNet Hub — consolidated responsive redesign QA (9 November 2026)

## Scope
The site is a React/Vite **staging** homepage under `afrinethub/` in `SMT-cmd/Unileh-PrintHub`. This pass specifically responds to mobile banner overflow, excessive hero height, non-visible text, cluttered pills, wordmark spacing and repeated/awkward copy. The existing live `afrinethub.com.ng` domain and Global Webstores were not altered.

## Changes made
- Rewrote all six hero slide headings/descriptions in concise, clear language, retaining real HTML text and a single actionable CTA.
- Removed the duplicate hero kicker, colored dot/pill next to the service eyebrow, service number pills and unnecessary image overlay badges.
- Tightened the stacked `AFRINET` / `HUB` wordmark with proper line-height, letter-spacing and alignment.
- Changed the benefits heading to **“We make everyday activities feel a little easier.”**
- Reduced hero panel dimensions and supporting section padding. Kept every hero photo behind a strong contrast gradient, and positioned live copy within the same single banner across breakpoints.
- Set autoplay to skip mobile screens; arrows and labelled dots remain available. Kept pause support for desktop.
- Consolidated conflicting CSS (previously `styles.css` + `editorial.css` + `banner-fix.css`) to `styles.css` + **`refinement.css`** only; old CSS files remain in source for history but are not imported.
- All five photographic service cards, campus panel, community banner and trust banner use live text over real imagery; reduced visual clutter and card heights.
- Preserved nine generated image assets, the accepted round logo and university watermark. No new standalone posters.
